# Security policy

TrackerLens reads code from other apps on the device, so parser robustness is a security
concern: a crafted APK that crashes, stalls or blinds the scanner is a valid report.

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/payallenka/trackerlens/security/advisories/new)
rather than a public issue. Include the Android version, the TrackerLens version and, if
possible, a minimal APK or DEX that reproduces the problem.
